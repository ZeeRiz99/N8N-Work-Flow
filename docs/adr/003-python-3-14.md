# ADR 003: Python 3.14 for the backend

- Status: Accepted (Phase 1, 2026-11-21)
- Amends: D4

## Context
D4 named Python 3.11–3.13. The only full install on the machine is Python 3.14.6 (a 3.12 Microsoft Store package also exists but is not a suitable base). Python 3.14 has been stable since October 2025; the backend's dependencies (FastAPI, Pydantic v2, SQLAlchemy 2, psycopg 3, Alembic, argon2-cffi, phonenumbers) are expected to ship 3.14 wheels.

## Decision
Use Python 3.14 in `backend\.venv`. If any required package has no working 3.14 wheel in Phase 2, install Python 3.13 (with approval) and record a follow-up ADR. CI uses the same minor version.

## Consequences
No extra install. A wheel problem is caught on the first `pip install` in Phase 2.
